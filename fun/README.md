# fun/

Personal mods, built around the author's own workflow and taste. Most people won't need or want these.

They're kept here so the author's full setup is backed up and can be restored on a new machine with `install.sh --all`. The regular install leaves them off.

If you're curious, turn one on with `mods on <name>`, or read the code as an example for building your own.

| Mod | What it is |
| --- | --- |
| [workbench](workbench/) | Side pane with the author's open PRs, next meeting, demo site links, plus a fun mode with a quote of the day, pizza and Mochi the 8-bit dino |
